### ER modeling
ER modeling (Entity–Relationship modeling) is a way to design and represent the structure of a database using entities, their attributes, and the relationships between them.

### What does ER modeling contain?

There are three main things:
```text
Entity
  ↓
Attributes
  ↓
Relationships
```
For example, in an e-commerce system:
```text
USER ───── places ───── ORDER
```
Here:
```text
User → entity
Order → entity
places → relationship
```
